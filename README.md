**https://kanhaiyathakur1941.github.io/upgrade2026/**

## Progress storage and backup

Progress, daily checks, project ticks, interview answers, and the context form stay in **this browser’s localStorage** under `upgrade2026-progress-v1`. Nothing is uploaded.

- **Export** downloads JSON. Keep a copy in a private folder after each study week.
- **Import** restores that JSON on this computer or another.
- **Reset** asks for confirmation and clears stored progress. It does not delete this HTML file.

## Update the lessons later

Edit files under `source/`, then from this folder:

```bash
python3 source/build.py
```

That rewrites `career_upgrade_master_documentation.html` only. It does not touch `Desktop/careerupgrade`.
